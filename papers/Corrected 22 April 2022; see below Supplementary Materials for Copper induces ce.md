## 方法概述

**Analysis of PRISM and repurposing datasets-** Growth-inhibitory data for 1,448 compounds screened against 489 cell lines at 8 doses from the PRISM Repurposing Secondary dataset (*10*) was analyzed to identify drugs with similar profiles of growth-inhibition to elesclomol. Replicate collapsed log fold change data was downloaded from depmap.org/repurposing (PRISM Repurposing 19Q4, Secondary Screen). Pearson correlation coefficients between all the profiles were calculated. For each pair of compounds, a similarity score was computed as the maximum absolute correlation between any two doses of the compounds. The distance between each compound pair was defined to be 1 -similarity score, and the pairwise distance matrix is embedded into a two-dimensional space using t-distributed stochastic neighbor embedding for the visualization purposes. The embedding procedure is implemented using the Rtsne R package with a perplexity of 10 and default settings. In the correlation analysis of PRISM data for elesclomol previously described (*5*) with the repurposing data (*10*) or FDX1 gene expression, the pearson's correlation (r) was computed for each profile, and p-values are computed using the corresponding t-statistics. The p-values are corrected for multiple hypothesis testing using Benjamini-Hochberg correction.

**Achilles correlation analysis**- The FDX1 network was visualized using FIREWORKS (*51*) with the rank(primary) set at 5.
